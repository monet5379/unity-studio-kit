# templates

새 Unity 프로젝트(또는 패키지 repo)를 시작할 때, 루트 `AGENTS.md`를 처음부터 쓰지 않도록 **복사해 채우는 뼈대**예요.

| 파일 | 프로필 |
|------|--------|
| [AGENTS.personal.md](AGENTS.personal.md) | 공개 패키지·실험 |
| [AGENTS.game.md](AGENTS.game.md) | 출시·팀 타이틀 |

## 쓰는 순서

1. 프로필을 고르세요 ([personal](../docs/personal/Overview.md) / [game](../docs/game/Overview.md)).  
2. 맞는 파일을 프로젝트 루트에 `AGENTS.md`로 복사해요.  
3. `<…>` 플레이스홀더를 채워요.  
4. Cursor에서 **이 프로젝트 + unity-studio-kit**을 멀티 루트로 열어요.

에이전트는 Kit의 `docs/<profile>/` · `.cursor/rules/<profile>/`와 이 `AGENTS.md`의 override를 함께 봐요. common은 항상 적용돼요.
